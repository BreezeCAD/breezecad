**молча делает неверно**. Где сейчас верно — поведение не меняется ни на байт.

## Пункт 1 — честный отказ вместо тихого переезда ссылки
Сейчас (BETA-BUGS №13) три сценария дают неверный результат со статусом «ОК».
1. **Пропавшая грань эскиза** (сценарий 3). У эскиза на грани есть `placement.support` — операция,
   сделавшая грань. Если она подавлена, в ошибке или удалена — эскиз получает предупреждение
   «Грань эскиза не найдена» (текст уже есть) и **остаётся на прежнем месте**, не переезжая на чужую грань.
   Если support жив — поведение прежнее (грань может уехать вдоль нормали — это законно, есть тесты).
2. **Рёбра.** Включи отказ только в доказуемо плохом случае: ребро уехало со старого места (> 1e-6) **и**
   есть другое ребро того же вида, почти так же близко (журнал `refs: N alike edges`). Тогда операция —
   предупреждение «Ребро не найдено однозначно — выберите заново», а не выбор наугад.
   Ребро на старом месте или единственное своего вида — как раньше, без сообщений.
   Порог подбери по журналу на настоящих деталях автора (закрытый `BreezeCAD/bz-test-corpus`
   и его файлы через MCP), чтобы ни одна рабочая деталь не получила новое предупреждение. Не подобрать
   порог без ложных срабатываний — остановись и опиши данные автору, не включай.
3. Тексты — через `Tr()`, словарь переводов дополни. Сценарии 1–2 набора `topology` после этого
   должны давать предупреждение, а не тихо неверный результат; сценарий 3 — проходить (сними `may_fail`).

## Пункт 2 — проверка `Clean()` вживую
`Clean()` уже проверяет результат слияния граней и откатывается (коммит `7a94b6e`). Нужно:
- прогнать корпус и детали автора, посчитать в журнале строки `Clean: merging faces …` —
  каждую разобрать (это случаи, где раньше молча портилось тело);
- замерить цену проверки: `tools/bench` до/после, на слабом железе — не дороже нескольких процентов.
  Дороже — облегчи проверку (например, объём считать только когда число граней изменилось), не убирая её.

## Пункт 3 — история операций (большой; сначала ADR, без автора формат не трогать)
1. Напиши ADR (следующий свободный номер в `docs/ADR/`): ссылки на элементы проходят через операции
   по истории OCCT (`Modified/Generated/IsDeleted` из `BRepAlgoAPI_*`, которые идут через `kernel/occt/Ops`),
   «портрет» элемента остаётся запасным путём. В файле `.bzc` в будущем — происхождение грани от
   элемента эскиза (`ObjectId`), не имена OCCT: формат открытый и не привязан к ядру.
   **Остановись и попроси автора одобрить ADR.**
2. Без изменения формата (только в памяти) — после одобрения: `Ops` отдаёт историю, пересчёт
   переносит по ней ссылки рёбер. Цель — сценарии 1 и 2 набора `topology` проходят (фаска остаётся
   на своём отверстии, скругление — на обоих кусках ребра), `may_fail` снимается.
3. Изменения формата — только отдельным шагом и только с явного «да» автора.
