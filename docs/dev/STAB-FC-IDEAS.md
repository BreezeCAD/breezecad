# Идеи из FreeCAD — ветка `stab/fc-ideas`

Ответвлена от `stab/3-ops-pipeline` (13.11.2026). Разбор FreeCAD (master от 13.11.2026)
и сравнение с нашим ядром — в чате 13.11.2026; здесь только то, что берём в код.

**Правило ветки:** ничего не переписываем, только добавляем с оглядкой. Каждое изменение
не должно менять результат на уже работающих деталях: полный `bz_tests` и эталоны corpus
до и после — одинаковые. Код FreeCAD (LGPL) не копируем — только идеи.

## Берём сейчас (малый риск)
1. **Проверка после слияния граней (`Clean`).** FreeCAD откатывает refine, если тело перестало
   быть замкнутым. У нас `Clean()` ловил только падение. Теперь: результат обязан остаться
   допустимым телом с тем же числом тел и тем же объёмом — иначе остаётся тело до слияния.
2. **Диагностика неоднозначных ссылок на рёбра** — только в журнал, без сообщений пользователю.
   Собираем данные на настоящих деталях, прежде чем делать ошибку «ребро не найдено однозначно».
3. **Каталог сценариев «топология изменилась»** (по мотивам тестов FreeCAD: разбить, обрезать,
   удалить линию эскиза и т. п.) — тесты с пометкой may_fail: фиксируют, где мы сейчас ошибаемся.

- Кэш топологии тела; допуск касания, ограниченный долей габарита; сплав инструментов перед вырезом.
