# ADR-0014. Неоднозначные ссылки на грани и рёбра

**Статус** — Proposed

**Дата** — 22.11.2026

## Контекст

После перестроения OCCT может изменить порядок, форму или состав граней и
рёбер. BreezeCAD хранит геометрические признаки ссылки. На деталях с похожими
гранями или круглыми кромками несколько кандидатов могут совпасть с ними.
Молчаливая перепривязка способна переместить отверстие либо изменить операцию.

## Решение

- Для ребра должны совпасть все сохранённые распознаваемые соседние грани.
  Поиск учитывает тип и направление кривой, радиус и положение. Для грани
  учитываются ориентация, положение плоскости и расстояние до сохранённой точки.
- Если два кандидата слишком близки по оценке, вернуть неоднозначный результат.
  Применяющий операцию код сообщает, что ссылку нужно выбрать заново.
- Когда вызывающий код знает плоскость исходной привязки, он может ограничить
  поиск копланарными прямыми и круглыми рёбрами. Для соосного отверстия
  принадлежность к плоскости проверяется по сохранённой грани, а кандидаты
  ищутся на её текущей плоскости. Ссылки на другой высоте продолжают разрешаться
  общим поиском. Пустой результат не меняет сохранённую ссылку.

## Последствия

Поддерживается существующий формат документов. Операция может потребовать
ручного выбора после изменения топологии. Явная плоскость помогает сохранить
привязку при перемещении опорной грани. Кэш топологии рассматривается для 0.2.7.

## Альтернативы

- Выбирать ближайшего кандидата при любом разрыве оценок. Это может перенести
  операцию на соседнюю геометрию без сигнала пользователю.
- Вводить новые постоянные идентификаторы топологии. Это требует отдельного
  решения о переносе истории операций и совместимости документов.
