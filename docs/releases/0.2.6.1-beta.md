# BreezeCAD 0.2.6.1-Beta

- **Скругления.** Если ядро OpenCASCADE аварийно завершает попытку построения, BreezeCAD
  продолжает проверять остальные рёбра. Для одного проблемного ребра программа пробует
  подобрать меньший радиус.
- **Проекция.** При наличии похожих соседних рёбер инструмент учитывает точное совпадение.
  На ограниченном участке скругления проецируются его собственные границы.
- **Выдавливание.** Для режимов «До» и «Насквозь» доступна фактическая глубина. Её можно
  использовать в формулах операций ниже по дереву.
- **Поликарбонат.** В «Живом виде» полупрозрачные поверхности лучше различимы, а отражение
  усиливается под скользящим углом.
